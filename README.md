# Өсімдік күтімі күнтізбесі 🌱

## Жоба туралы
Бұл жоба өсімдіктерге күтім жасау жұмыстарын
жоспарлауға арналған.

## Жобаның мақсаты
Өсімдіктерді суару, тыңайтқыш беру және
күтім жасау уақытын бақылауды жеңілдету.

## Негізгі мүмкіндіктері
- Пайдаланушыларды тіркеу
- Өсімдіктерді қосу
- Күтім күнтізбесін жасау
- Еске салғыштар
- Күтім тарихын сақтау

## Деректер базасы
Жобаның ER-диаграммасы жасалған.
